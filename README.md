# 🛍️ Store Management System

## 📌 About the Project

**Store Management System** is a front-end web application developed as part of **Assignment 10**. The project provides a simple and user-friendly interface for managing product inventory.

Built using **HTML, CSS, and JavaScript**, the application allows users to add products, display product information, update existing products, and delete products. It also includes search and category-filtering features to make managing inventory easier.

The interface includes a product form, product search fields, a product inventory section, and a clean layout designed to provide a straightforward user experience.

## ✨ Features

- **Create Products:** Add new products with their names, prices, categories, descriptions, and images.
- **Display Products:** View product information in the inventory section.
- **Update Products:** Edit existing product information.
- **Delete Products:** Remove products from the inventory.
- **Search Products:** Search for products by name.
- **Filter by Category:** Find products based on their categories.
- **Product Images:** Add images to products to improve their presentation.
- **User-Friendly Interface:** Simple and organized layout for easier navigation.
- **Responsive Design:** CSS styling designed to provide a better experience across different screen sizes.

## 🛠️ Technologies Used

- **HTML5:** Structures the application, including the product form, input fields, buttons, and inventory section.
- **CSS3:** Handles the visual design, layout, colors, spacing, and responsive styling.
- **JavaScript (ES6+):** Implements the application logic, CRUD operations, product searching, category filtering, and dynamic UI updates.

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser to run this project.

### Installation and Setup

1. Clone the repository:

   ```bash
   git clone <YOUR_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd Assignment-10
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code for a smoother development experience.

## 💡 How to Use

1. Enter the product name and price.
2. Select or enter the product category.
3. Add a product image if needed.
4. Write a product description.
5. Click **Add Product** to add the product to the inventory.
6. Use the search field to find a specific product.
7. Use the category filter to display products from a particular category.
8. Use the available edit and delete actions to manage existing products.
